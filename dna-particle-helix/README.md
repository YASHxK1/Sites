# DNA Particle Helix

A full-screen black canvas with two flowing swarms of glowing white particles that form a rotating DNA double helix. Built with Three.js and a GPU particle shader. Mouse movement gently shifts the helix; the layout adapts to mobile screens and respects reduced-motion preferences.

## Run locally

```bash
npm install
npm run dev
```

Open the URL printed by Vite. To make a production build, run `npm run build`; the output is in this folder's `dist/` directory.

This site is independent of the other site folders in this repository. Install and run it from this directory.
